#### マップ

- 縦に長い巨大な城を攻略。上に行くほど太い。
- ドアを開けないと中が見えない
- 1層は5階で構成。
- その層の一番階はボス階。ボス階以外のマップはランダム生成。下への階段と上への階段の位置もランダム。
- ボス階のマップは固定。ボス部屋とショートカットがある。
- BSP + Room Templatesの組み合わせ(構造はBSPで決め、実際の部屋はテンプレートから選択)
- 店の部屋があったりする。そこで武器を売ったり買ったりできる。

#### 第1層: 玄関

- 舞台設定:塔の最下層。石造りの重厚な内装。
- 部屋の傾向:玄関ホール、衛兵詰所、控えの間、小さな礼拝堂。閉所戦が中心で、TPSのカバー要素より近距離の索敵と遭遇の緊張感を重視。

#### 第2層: 兵舎

- 舞台設定:モンスター軍勢の生活・訓練区画。松明の煤で黒ずんだ石壁、粗雑に組まれた木製の足場や増築跡が目立つ、雑然とした実用空間。
- 部屋の傾向:大部屋の兵舎、鍛冶場、武器庫、訓練場(中庭的な吹き抜け)。敵の数が増え始め、遮蔽物(木箱・武器棚)を使ったカバー戦が主体に。訓練場では中距離の撃ち合いも発生。

#### 第3層: 牢獄区画

- 舞台設定:石造りから鉄格子と鎖の多い陰鬱な造りに変化。松明が減り、暗がりと水滴の音が支配する湿った空間。
- 部屋の傾向:独房群、拷問室、看守詰所、地下水路への入口。閉所と暗闇を活かした索敵メインの緊張感に加え、鍵や仕掛け探索の探索要素も絡む。囚われた存在との遭遇イベントも配置可能。

#### 第4層: 儀式回廊

- 舞台設定:モンスターの魔力が色濃く現れる層。石材に紫や緑の魔法紋様が発光し、浮遊する瓦礫や歪んだ回廊など非現実的な建築に変貌。
- 部屋の傾向:祭壇の間、魔法図書庫、召喚陣のホール、歪んだ長回廊。中距離〜遠距離の撃ち合いができる開けた祭壇部屋と、狭い回廊での近接戦が交互に来る緩急のある構成。遠隔攻撃の術者敵を配置しやすい。

#### 第5層: 玉座の間

- 舞台設定:城の最深部。黒曜石や骨、金の装飾が入り混じる異形の玉座広間。天井が高く開けた大空間で、これまでの層の要素(石・鎖・魔法紋様)が集約されたデザイン。
- 部屋の傾向:謁見の間、玉座広間(ボス戦フィールド)、宝物庫。ボス戦を想定した広い可動範囲と複数の遮蔽物、高低差のあるステージ構成。TPSのカバー撃ち合いとボスの範囲攻撃回避を両立させる設計。
